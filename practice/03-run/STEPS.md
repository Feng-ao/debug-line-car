# 03-run · 四轮驱动架空转向测试

- 日期：2026-10-15
- 目标：TB6612 + TIM3 双通道 PWM 驱动四轮，架空验证四轮转向正确（车体向前）
- 结果：**通过**（复测四轮全部向前，见文末修正记录）

## 1. 硬件接线

### 电机并联（TT 马达 ×4，每台一红一黑）

同侧两台电机共用 TB6612 一路输出，靠面包板同一竖列实现"拧在一起"：

| 绞合组 | 接 TB6612 |
|---|---|
| 左前红 + 左后红 | AO1 |
| 左前黑 + 左后黑 | AO2 |
| 右前红 + 右后红 | BO1 |
| 右前黑 + 右后黑 | BO2 |

### TB6612 电源

| 引脚 | 接线 | 备注 |
|---|---|---|
| VM | 电池正极 | 电机动力电 |
| VCC | STM32 3.3V | 逻辑供电，不接电池 |
| GND | 电池负极 + STM32 GND | 必须共地 |
| STBY | 3.3V | 芯片使能，不接电机不转 |

### 控制线（STM32 → TB6612）

| STM32 | TB6612 | 作用 |
|---|---|---|
| PA6 | PWMA | 左轮 PWM（TIM3_CH1）|
| PA7 | PWMB | 右轮 PWM（TIM3_CH2）|
| PA5 | AIN1 | 左轮方向 |
| PA8 | AIN2 | 左轮方向 |
| PA11 | BIN1 | 右轮方向 |
| PA12 | BIN2 | 右轮方向 |

## 2. 软件配置（run.ioc）

- 时钟：HSE 8MHz × PLL9 = **72MHz**
- TIM3 双通道 PWM：Prescaler=71，Counter Period=999 → **1kHz，占空比 0–999**
- PA5/PA8/PA11/PA12：GPIO 推挽输出，标签 AIN1/AIN2/BIN1/BIN2
- 编译器：AC6（本机 AC5 无授权），工程内已固化 `<uAC6>1</uAC6>`

## 3. 测试程序（Core/Src/main.c）

循环执行：

```
左轮正转 2s（AIN1=1, AIN2=0, 占空比 700）
→ 左轮停 1s（PWM=0, AIN1=0）
→ 右轮正转 2s（BIN1=1, BIN2=0, 占空比 700）
→ 右轮停 1s（PWM=0, BIN1=0）
```

烧录：ST-LINK 接 PA13/PA14 + 3.3V 供电，**烧录前拔电池**。

## 4. 测试与修正记录

1. **首测（14:02）**：时序正确；同侧前后轮转向相反（前轮向前、后轮向后）
   - 原因：前后电机镜像安装，红/黑线焊片方向未对齐；并联后同侧两轮共用一路信号，软件无法单独修正
   - 修正：后轮电机在面包板端换列（左后：红 AO1↔AO2、黑 AO2↔AO1；右后：BO1↔BO2），不动焊点
2. **复测（14:16）**：四轮全部向前，**测试通过**

## 5. 踩坑记录

- STBY 跳线误插 GND 列 → 3.3V 与 GND 短路，降压模块发烫。教训：**上电池前必测 3.3V↔GND 不通**
- 蜂鸣档量 AO1↔AO2 会响 ≠ 短路：电流经电机绕组（实测 3.7Ω）导通属正常；真短路的判据是电阻档读数 0Ω
- 电机线镀锡头直插面包板可用，但跑动后若出现电机时转时停，第一嫌疑是插孔接触松动
